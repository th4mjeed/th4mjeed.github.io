# th4mjeed.github.io

Redirect repository.

This GitHub Pages site forwards `https://th4mjeed.github.io` (and any subpaths) to the real site at **https://th4mjeed.pages.dev**.

- `index.html` — redirects the homepage (root path)
- `404.html` — redirects every other path (e.g. `/writeups/...`) preserving the URL path, so old deep links keep working

The actual site source lives in the **th4mjeed-portfolio** repository.
